# Typographic Book

An interactive typographic book artwork with a constrained 3D camera.

## Embed

```tsx
import { TypographicBook } from './typographic-book'

;<TypographicBook backgroundColor="#f01808" />
```

Drag to orbit; use the on-screen controls or keyboard to zoom and reset. The lettering is a fixed composition. `backgroundColor` changes the background; `className` styles the wrapper.
