# Library

The library is organized as `category/entry`. Category folders define placement boundaries; entry folders contain one focused component, effect, or experiment.

Before adding an entry, read the relevant category README and choose the category that represents the entry's main reusable idea. Before adding a category, follow the stricter category protocol in the repository root README.

The showcase discovers entries from their `meta.ts` files. Demo modules and entry documentation remain lazy-loaded until their detail route is opened.
